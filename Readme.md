# PawsHome - Pet Adoption Platform (Client)

## Purpose
PawsHome is a full-stack pet adoption platform where users can browse pets available for adoption, view detailed pet profiles, and submit adoption requests. Pet owners can manage their listings and handle adoption requests.

## Live URL
🌐 https://pawshome-client.vercel.app/
## Features
- 🐾 Browse all available pets with search, filter, and sorting
- 🔐 Secure authentication with Email/Password and Google Login
- 📋 Submit and manage adoption requests
- 🏠 Pet owners can add, update, and delete pet listings
- ✅ Approve or reject adoption requests
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🔔 Toast notifications for all actions
- 🔒 JWT-based private route protection
